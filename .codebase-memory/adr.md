# ADR addendum: cancel_timer (discard) — 2026-08-20

BubbleWidget.cancel_timer(habit_name) discards a running session with zero side effects on the sync pipeline: it cancels any pending auto-detect grace stop, pops `self.timers`, clears the square's running state, saves state, flashes "timer discarded", and notes the manual toggle (started=False) so auto-detect suppresses re-start until the mapped window loses focus. Crucially it never calls append_event — the bridge queue is untouched, so nothing reaches the phone. Exposed as "Cancel timer (discard)" in the square right-click menu (trashcan icon, enabled only while running). Verified headlessly: monkeypatched append_event observes zero calls; timer + grace entries dropped; no-op safe when idle.
